## Erreurs rencontrées
- [ERR-VITE-001] Conflit de version Vite (`vite@^8.0.0` non existant) bloquant l'installation des dépendances.
  - Solution : Forcer la version de `vite` à `^6.0.0` dans `package.json`.
- [ERR-ESBUILD-001] `Transforming destructuring to the configured target environment is not supported yet` sur `date-fns` v4.
  - Cause : ESBuild n'arrive pas à traduire la destructuration de tableau moderne vers les cibles d'anciens navigateurs par défaut de Vite 6.
  - Solution : Mettre `target: 'es2022'` et `supported: { 'destructuring': true }` dans `vite.config.ts`.
