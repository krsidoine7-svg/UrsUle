  - Création de 7 scénarios Python dans `.skills/locust-template/scenarios/` pour simuler jusqu'à 1000 utilisateurs concurrents.
- [17:00] [BUG] Figeage de l'éditeur de notes (`NoteEditor.vue`) lors du clic sur une carte dans la liste :
  - Cause : *Race condition* dans `@tiptap/vue-3`. L'instance `editor.value` monte de manière asynchrone et vaut `undefined` au premier cycle de rendu, provoquant l'abandon du watcher sur les props initiales.
  - Solution : Ajout du hook `onCreate({ editor })` directement dans `useEditor` pour initialiser le document si les props sont prêtes + ajout de `editor.value` dans les dépendances du `watch` avec `{ immediate: true, deep: true }`.
- [17:10] [BUG] Bloquage de transition de routes dans `BrainView.vue` :
  - Solution : Attachement de `:key="route.fullPath"` sur `<component :is="Component" />` à l'intérieur du `<router-view>` pour forcer un montage propre à chaque transition de note ou dossier.
- [17:12] [UI] Troncatures et ergonomie (`NoteListView.vue`, `FolderTreeNode.vue`) :
  - Assouplissement de la hauteur des cartes en mode grille (`min-h-[10rem] h-auto` au lieu de `h-40`).
  - Ajout d'attributs `:title` sur les titres de notes et noms de dossiers pour accessibilité complète au survol.
  - Ajout du badge exact de décompte de notes dans l'en-tête du dossier.
- [17:15] [PERF] Création de la migration `023_performance_indexes.sql` pour optimiser les recherches GIN plein texte et les jointures B-tree.
