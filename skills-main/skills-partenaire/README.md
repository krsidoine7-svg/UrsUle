# Skills partenaires — catalogue UrsUle

Skills issus d'**Anthropic**, **Softaworks/agent-toolkit** et intégrations MCP. Orchestrés par **ChefsUrsUle** via [`skills_manifest.md`](../../.skills/ChefsUrsUle/references/skills_manifest.md).

## Règles d'utilisation

1. **Priorité UrsUle** : si un skill natif existe (ex. `skill-mermaidH`, `memoire-favor`), l'utiliser en premier.
2. **Nouveau skill** : passer par `skill-creator/` puis validation ChefsUrsUle (standard 5 étoiles).
3. **Audit qualité** : `skill-judge/` pour évaluer un SKILL.md avant intégration.
